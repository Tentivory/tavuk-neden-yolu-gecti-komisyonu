# Tavuk Neden Yolu Geçti Ulusal Araştırma Komisyonu

> Bu depo, insanlık tarihinin en önemli sorularından birini **resmî tutanak diliyle** çözmek üzere kurulmuştur.
> Tavuk yolu geçmiştir. Komisyon henüz geçmemiştir.

## Misyon

Tavukların yol geçiş motivasyonunu;

- bilimsel,
- bürokratik,
- biraz da uykulu

bir üslupla belgelemek.

Bu yazılım çalışır. Gerçekten çalışır. Karar çıkarması ayrı meseledir.

## Kuruluş

```bash
python3 komisyon.py
```

Çıktı bir tutanak olacaktır. Tutanak her çalıştırmada değişir çünkü gerçek hayatta da değişir.

## Teknik Özellikler

| Özellik | Değer |
|---|---|
| Dil | Türkçe (resmî, hafif abartılı) |
| Karar süresi | sonsuz |
| Çay tüketimi | yüksek |
| Alt komisyon sayısı | bir fazlası |
| Test kapsama oranı | tavuk bakışıyla %100 |

## Katkıda Bulunma

Yeni bir sebep önermek için issue açın. Issue şablonu vardır. Şablon da komisyon gibidir: sorar, cevaplamaz.

Pull request gönderebilirsiniz. Review süresi en az bir tavuk ömrüdür.
